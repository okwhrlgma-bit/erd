# 선행 조사: ERD 그리기 (2026-10-19)

> 이 표의 erdcloud, dbdiagram, chartdb, liam 설명은 DEV-QUEUE 35 판정과 수요 실측 보고서에서 옮긴 것이다. 각 사이트를 이 창립에서 다시 열어 써 보지는 않았다.

| 제품 | 한 줄 정체 | 이 앱과 다른 점 (판정 인용) |
|---|---|---|
| drawdb (https://github.com/drawdb-io/drawdb) | 우리가 고친 상류. AGPL-3.0 브라우저 ERD 편집기 | 영어 화면이 기본이고 서버 공유가 있다. 우리는 한국어 기본, 서버 호출 0 |
| erdcloud | 한국어 ERD 서비스 | 가입이 필요하다고 판정에 적혀 있다. 우리는 가입 0 |
| dbdiagram | 코드로 그리는 ERD 서비스 | 개수 제한이 있다고 판정에 적혀 있다. 우리는 제한이 없다 |
| chartdb | DDL 붙여넣기로 ERD 를 만드는 도구 | 기제 참고만 했다. 이 앱에는 SQL 가져오기 메뉴가 상류에 있다 |
| liam | 보기 전용 ERD 도구(Apache-2.0) | 2순위로 두었다 |
